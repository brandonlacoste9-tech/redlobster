Core Capabilities

Your machine, supercharged

OpenClaw runs locally on your hardware with direct system access — no cloud middleware, no API proxies, just raw execution power.

⚡

Shell Execution

Run terminal commands, execute scripts, and manage your local environment. Full shell access from any messaging app.

📁

File Management

Read and write files directly to disk. Maintains memory and project context in plain Markdown and YAML files.

🌐

Browser Automation

Uses Chrome DevTools Protocol to see and interact with websites — filling forms, scraping data, taking screenshots.

🧠

Local LLM Support

Works seamlessly with Ollama or LM Studio. Run your entire agentic stack offline — fully private and on-device.

A Note on Security

Because OpenClaw has shell and file access, it's widely recommended to run it in a sandboxed environment or a dedicated VPS rather than your primary daily-driver machine to mitigate risks from unvetted community skills. Always review skills before installing and keep your gateway authenticated.
